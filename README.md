# Cisco Packet Tracer Networking Labs

This repository contains my hands-on practice and networking
labs completed using Cisco Packet Tracer as part of my CCNA learning.

## Labs

| Lab | Concept |
|---|---|
| ACL | Access Control List |
| BGP | Border Gateway Protocol |
| Blackhole Routing | Blackhole Routing |
| Dynamic Routing | Dynamic Routing |
| Extended ACL | Extended Access Control List |
| LAN | Local Area Network |
| NAT | Network Address Translation |
| PAT | Port Address Translation |
| Port Security | Switch Port Security |
| Standard ACL | Standard Access Control List |
| Static Routing | Static Routing |
| VLAN | Virtual LAN |

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI

## Repository Contents

Each lab contains:

- `.pkt` — Cisco Packet Tracer project file
- `topology.png` — Network topology
- `result.png` — Configuration/verification result
