# Cisco Packet Tracer Networking Labs

This repository contains my hands-on practice and networking
labs completed using Cisco Packet Tracer as part of my CCNA learning.

## Topics Practiced

- Basic Network Configuration
- IP Addressing
- VLAN Configuration
- Routing
- DHCP
- Network Connectivity
- Switch Configuration
- Router Configuration

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI

## Repository Structure

Each folder contains the Packet Tracer `.pkt` file, screenshots,
and a brief explanation of the networking concept practiced.
